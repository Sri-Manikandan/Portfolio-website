# Sri Manikandan R - Portfolio Website

A modern, responsive portfolio website built with React and Tailwind CSS, showcasing my projects, experience, and skills in AI/ML and full-stack development.

## Live Demo

[srimanikandan.netlify.app](https://srimanikandan.netlify.app/)

## Tech Stack

- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Fonts:** Syne, DM Sans, JetBrains Mono

## Features

- Dark editorial design with electric teal accents and glow-card hover effects
- Fully responsive across mobile, tablet, and desktop
- Smooth scroll navigation with glassmorphism navbar
- Scroll-triggered animations on all sections
- Dot-grid background with noise texture overlay

## Sections

- **Hero** - Introduction with resume and GitHub links
- **About** - Summary with stats (projects, hackathons, companies)
- **Experience** - Timeline of work experience
- **Projects** - AI/ML project showcase with GitHub links
- **Skills** - Categorized skill bars (AI & ML, Frontend, Backend, DevOps & DB)
- **Education** - Academic background with grades
- **Contact** - Email, phone, location, and social links

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
